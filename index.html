🎯 Что выбрать — 3 сценария

Сценарий 1: «Хочу красивую вещь на стол, которая отвечает на вопросы»
→ XiaoZhi AI Robot Ball ($24, AliExpress)
Xiaozhi из коробки. Поднимаешь сервер (или юзаешь xiaozhi.me), подключаешь Perplexity. Круглый дисплей с лицом. Доставка 2-3 недели. Идеально как первый шаг.

Сценарий 2: «Хочу большой экран и камеру в красивом корпусе»
→ UNIHIKER K10 ($52, Amazon)
Ставишь Xiaozhi (есть YouTube туториал). Получаешь 2.8" сенсорный экран + камеру + микрофон + динамик в аккуратном корпусе. Доставка за 2 дня.

Сценарий 3: «Хочу настоящую премиум колонку как Sonos с голосовым ассистентом»
→ Satellite1 ($135-200, предзаказ)
Лучший звук, лучший дизайн, 4 микрофона. Но — только HA экосистема. Если HA не нужен — не твой вариант. Если HA есть — лучшее что можно купить.

💡 Совет по Xiaozhi + Perplexity

1. Покупаешь XiaoZhi Robot Ball за $24 на AliExpress
2. Подключаешь к Wi-Fi через приложение
3. Поднимаешь Xiaozhi Server на любом VPS ($5/мес) или RPi дома
4. В конфиге сервера указываешь Perplexity API (OpenAI-compatible)
5. Всё. Колонка отвечает через Groq → Perplexity → ElevenLabs
6. Если нужен умный дом — MCP/MQTT для управления устройствами
