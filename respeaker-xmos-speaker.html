2 Инструкция по сборке железа
Пошаговое руководство по физической сборке компонентов.
Шаг 1

Распакуй и осмотри ReSpeaker Kit

Достань из коробки **XMOS XVF3800 плату**, **XIAO ESP32S3**, акриловый корпус и USB-C кабель. **XIAO ESP32S3 пока не вставляй в разъём на XMOS плате.**

Шаг 2

Собери акриловый корпус

Следуй инструкции из комплекта. Обычно это несколько слоев акрила, которые собираются как сэндвич. **Не закрывай корпус полностью**, тебе нужен доступ к плате для подключения усилителя и динамиков.

Шаг 3

Установи XMOS XVF3800 плату в корпус

XMOS плата должна удобно расположиться внутри корпуса. Зафиксируй её винтами, если предусмотрено.

Шаг 4

Подключи усилитель PAM8403 к ReSpeaker XVF3800

XMOS XVF3800 имеет встроенный ЦАП (DAC) и выдает аналоговый аудиосигнал. Найди на плате XVF3800 пины аналогового аудиовыхода (например, **OUT_L, OUT_R, GND**).

Подключи:

  • OUT_L (XMOS) → **L** (PAM8403)
  • OUT_R (XMOS) → **R** (PAM8403)
  • GND (XMOS) → **GND** (PAM8403)

Используй провода Dupont для аккуратного соединения. Если нет Dupont, придется паять. Также подключи **питание PAM8403**:

  • 5V (XMOS или XIAO ESP32S3) → **VCC** (PAM8403)
  • GND (XMOS или XIAO ESP32S3) → **GND** (PAM8403)

Внимание: Убедись, что XIAO ESP32S3 (или XMOS плата) может выдать достаточный ток для усилителя (до 1.2А при 5V). Общий USB-C блок питания на 5V/3A должен обеспечить достаточно мощности для всей системы.

Шаг 5

Подключи динамики к усилителю PAM8403

На усилителе PAM8403 есть 4 клеммы: **L+, L-, R+, R-**.

  • Подключи первый динамик к **L+** и **L-**.
  • Подключи второй динамик к **R+** и **R-**.

Постарайся соблюдать полярность для лучшего качества звука. Скорее всего, понадобится пайка.

Шаг 6

Установи XIAO ESP32S3 на XMOS XVF3800

Осторожно вставь XIAO ESP32S3 в соответствующий разъём на XMOS XVF3800. Убедись, что все пины совпали и плата сидит плотно.

Шаг 7

Финальная сборка корпуса

Аккуратно уложи все провода внутри корпуса, чтобы они не мешали и не касались движущихся частей (если есть). Закрой корпус, закрутив все винты.

Шаг 8

Подключи USB-C блок питания

Подключи блок питания 5V, 3A к USB-C порту на **XIAO ESP32S3**. Устройство должно включиться, RGB LED на ReSpeaker XVF3800 должны засветиться.

3 Прошивка и настройка ПО
Настройка ESPHome и Home Assistant для интеграции LLM.
Шаг 1

Подготовь Home Assistant

Убедись, что у тебя установлен и работает Home Assistant. Установи дополнение **ESPHome** в Home Assistant (Supervisor -> Add-on Store -> ESPHome).

Шаг 2

Создай новый девайс в ESPHome

Открой веб-интерфейс ESPHome. Нажми + NEW DEVICE. Дай имя своему девайсу (например, respeaker-xmos-speaker). Выбери ESP32-S3 как тип платы. Скачай сгенерированный .yaml файл конфигурации.

Шаг 3

Настрой .yaml файл для ReSpeaker XVF3800

Тебе нужно добавить специфичные настройки для XMOS XVF3800 и аудио в этот .yaml файл. Вот пример. **Важно: пины (GPIO) могут отличаться**, сверяйся с документацией ReSpeaker XVF3800 и XIAO ESP32S3.

esphome:
  name: respeaker-xmos-speaker
  platform: ESP32S3
  board: esp-wroom-32s3-devkitc-1 # Или другая плата ESP32S3, совместимая с XIAO ESP32S3

wifi:
  ssid: "ТВОЯ_WIFI_СЕТЬ"
  password: "ТВОЙ_ПАРОЛЬ_ОТ_WIFI"
  ap:
    ssid: "Respeaker Fallback"
    password: "password"

logger:

api:
  encryption:
    key: "ОЧЕНЬ_СЕКРЕТНЫЙ_КЛЮЧ_ДЛЯ_HA" # Сгенерируй случайную строку, 16 символов

external_components:
  - source: github://prickle-uk/esphome-xmos-respeaker@main
    components: [ xmos_respeaker ]

xmos_respeaker:
  id: xmos_audio
  # I2C пины для связи ESP32S3 с XMOS. Проверь документацию XIAO ESP32S3.
  i2c_sd_pin: GPIO33 
  i2c_scl_pin: GPIO34
  # Дополнительные настройки XMOS (mute, led) см. в документации esphome-xmos-respeaker

voice_assistant:
  microphone:
    source: xmos_respeaker # Используй компонент XMOS как источник микрофона
    id: internal_mic
  # speaker: - не настраиваем здесь, так как XMOS уже выводит аналоговый сигнал на усилитель

# Опционально: Wake word (требует много RAM, но ESP32S3 с 8MB PSRAM потянет)
wake_word:
  - platform: openwakeword
    model: "hey_nabu" # Пример wake word, можно поменять

# Управление RGB LED кольцом на XMOS XVF3800 (если есть доступные GPIO и драйвер)
# light:
#   - platform: neopixelbus
#     type: GRB
#     pin: GPIO_RGB_LED_PIN # Замени на реальный GPIO пин
#     num_leds: 4 # Количество светодиодов
#     id: speaker_lights

# media_player (если хочешь воспроизводить музыку из HA)
media_player:
  - platform: i2s_audio
    id: media_out
    # !!! Внимание: I2S выходы XMOS XVF3800 уже подают сигнал на PAM8403.
    # Этот media_player здесь будет не нужен, если ты уже используешь аналоговые выходы XVF3800.
    # Если же XMOS_respeaker компонент в ESPHome может напрямую управлять XMOS для воспроизведения, 
    # то возможно понадобится его использовать. Для начала оставь закомментированным.
Шаг 4

Прошей ESP32S3

Подключи **XIAO ESP32S3** к компьютеру через USB-C. В веб-интерфейсе ESPHome нажми UPLOAD для своего девайса. Выбери **Web Flasher** для прошивки через браузер.

Шаг 5

Настрой Home Assistant Assist для LLM (Perplexity)

После успешной прошивки, твой девайс появится в Home Assistant. Перейди в **Home Assistant: Settings -> Voice**.

В разделе **Assist pipeline** создай новый или отредактируй существующий:

  • Speech-to-Text (STT): Выбери Home Assistant. Твой ESPHome девайс будет передавать распознанный текст сюда.
  • Language Model (LLM):
    • Добавь нового Conversational Agent.
    • Выбери OpenAI Conversation.
    • В настройках OpenAI Conversation укажи:
      • API key: **Твой Perplexity API ключ.**
      • Base URL: https://api.perplexity.ai/
      • Model: sonar-pro (или sonar-deep-research для более глубоких ответов).
    • Настрой другие параметры (температура, системный промпт).
  • Text-to-Speech (TTS): Выбери Home Assistant. Твой ESPHome девайс будет воспроизводить TTS, который ему передаст HA.

В **Audio output device** в Home Assistant выбери твой девайс: respeaker-xmos-speaker.

4 Что ожидать
  • Качество микрофонов: Благодаря XMOS DSP, распознавание речи будет отличным, даже в шумных условиях.
  • Качество звука: Зависит от выбранных динамиков и усилителя. PAM8403 + хорошие 3-5W динамики дадут приемлемое качество для голосовых ответов и фоновой музыки.
  • Дизайн: Акриловый корпус из комплекта функционален. Для "премиум" дизайна ищи 3D-модели (поиск respeaker xvf3800 case) и заказывай печать.
  • Время сборки: Железо 1-2 часа. Прошивка и настройка ПО 1-3 часа.
  • Доставка: Seeed Studio и AliExpress обычно доставляют на Кипр за 10-20 дней. Amazon DE быстрее (3-5 дней).

Важно: Этот проект требует базовых знаний электроники (подключение проводов) и работы с Home Assistant/ESPHome. При возникновении проблем, ищи помощь в сообществах Home Assistant и Seeed Studio.
